# Ames Housing dataset

Place the ames_train.csv file here. It should be the train.csv dataset from Kaggle's "House Prices: Advanced Regression Techniques" competition, which is based on the Ames Housing dataset (De Cock, JSE, 2011).

Link: [https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data](https://www.kaggle.com/datasets/shashanknecrothapa/ames-housing-dataset/data)

Required columns: GrLivArea, TotalBsmtSF, GarageArea, YearBuilt, OverallQual, MSZoning, SalePrice.
